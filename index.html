What each phase does

01 · Lexical analysis

Groups characters into identifiers, keywords, literals, operators and punctuation. Reports unknown characters with line and column.

02 · Syntax analysis

A recursive-descent parser checks grammar and builds an abstract syntax tree for declarations, assignments, expressions, conditionals, loops and print statements.

03 · Semantic analysis

Tracks declared names and inferred types, catches undeclared reads and incompatible assignments, and records symbols.

04 · Intermediate representation

Converts expressions into three-address instructions with temporary values and explicit labels for control flow.

05 · Optimization

Performs safe constant folding and simple algebraic simplification while preserving the supported language's behavior.

06 · Code generation & execution

Emits readable virtual-machine instructions and runs the supported program in a bounded local interpreter.

Learning studio

Quick reference for compiler design concepts and this project's implementation.

⌗

Lexical analysis

The lexer scans source characters and creates tokens. Each token carries a type, value, line and column.

let score = 10;
⌘

Parsing & AST

The parser applies grammar rules and turns tokens into a tree that represents program structure.

Binary(+, 2, 3)
✓

Semantic checks

Syntax can be valid while meaning is invalid. Symbol tables track declarations and types.

let x = missing;
⇄

Intermediate code

Three-address code makes complex expressions easier to optimize and translate.

t1 = 2 * 3
t2 = 4 + t1
⚡

Optimization

Constant folding computes expressions made entirely from constants at compile time.

4 + 2 * 3 → 10
▤

Code generation

The backend maps the intermediate representation to a simple virtual instruction set.

LOAD_CONST 10
STORE score

CV-Lang quick syntax

Declarationslet count = 3;
let label = "hello";
Control flowif (count > 0) { print(count); }
while (count > 0) { count = count - 1; }
Expressions+ - * / %
== != < > <= >= && || !

This is an educational, deliberately small C-like language—not a full C/C++ compiler. Functions, arrays, pointers, native machine-code output and advanced data-flow optimization are not implemented.
